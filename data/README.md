## 字段说明（每条记录 12 个字段，顺序固定）

|---|---|---|---|

| `code` | 职位代码 | string | 8-12 位数字，保留前导零，**见下方"重要警示"** |
| `count` | 招考人数 | number | 整数，≥1 |
| `major` | 专业 | string | **专业要求原文，未做任何归类/展开清洗**（前端请做模糊/包含匹配，勿假设目录结构） |
| `edu` | 学历 | string | 9 种：仅限大专/大专或本科/大专及以上/仅限本科/本科及以上/本科或硕士研究生/仅限硕士研究生/硕士研究生及以上/仅限博士研究生 |
| `degree` | 学位 | string | 如"学士"、"硕士"、"博士"、"与最高学历相对应的学位"、"无要求" |

### 未纳入的字段（官方原表存在，按需求字段表未采集）

部门代码、用人司局、机构性质、职位属性、职位分布、职位简介、考试类别、服务基层项目工作经历、是否在面试阶段组织专业能力测试、面试人员比例、落户地点、部门网站、咨询电话1-3。如需扩展，改 `build-data.js` 列索引即可从原始 xls 重新生成。

### apps / ratio（报名人数、竞争比）：**缺失**

官网现仅挂面试/调剂/补充录用阶段文件，报名期每日报名统计全量表未再提供；第三方（华图职位库）虽有合格人数但需逐岗抓取 2 万页，未采集。故全部记录无 `apps`/`ratio` 字段。如需补充，可在报名期每日抓取官网统计，或接入华图职位库。

## 清洗规则

1. 取 4 个 sheet（中央党群机关 / 中央国家行政机关（本级） / 中央国家行政机关省级以下直属机构 / 中央国家行政机关参照公务员法管理事业单位），表头一致，跳过每个 sheet 的免责声明行与表头行，按"职位代码非空"判定数据行；
2. 所有字符串字段：CRLF/CR → LF，全角空格/不间断空格 → 半角空格，去首尾空白；
3. `count`：parseInt，非法则剔除该行并记录（实际 0 条剔除）；
4. `org`：按上表归一为 中央/省级/市县级 三档；
5. `major`：**保留原文**；仅当为空时置"不限"（实际仅 1 条本身就是"不限"原文：400110125011 国家统计局云南调查总队，另 0 条为空），未做任何专业目录归类；
6. `note`：允许为空（315 条官方原表为空），其余字段不得为空（校验通过）；
7. 未做去重——见下方警示，重复的 code 是真实独立职位。

## 重要警示：职位代码（code）在全表不唯一

官方原始数据中，**同一 `code` 可被不同部门的不同职位复用**（例如 `100110001001` 同时是中央办公厅、中央对外联络部、中央台办、中央金融办、全国政协、民进中央、农工党中央、致公党中央、台盟中央共 9 个职位）。code 仅在部门内唯一。

- 校验：`(code, dept, position)` 组合 20,714/20,714 全表唯一，零重复行——不存在解析错误，不能去重；
- **前端定位/收藏/对比职位请勿以 `code` 为唯一键**；用 `code + dept` 组合键，或直接用数组下标作内部 id。

## 派生切片文件（D2 性能优化，2026-10-11）

由 `../build-slices.mjs` 生成（`node build-slices.mjs`，可重复运行覆盖），**不修改 jobs-2026.json 原始文件**：

- `index.json`：轻量筛选索引，1,690,389 字节（1.61 MB），首屏加载。字典编码（d=部门/p=职位/m=专业/e=学历/l=地点/c=政治面貌/t=年限/o=层级）+ 紧凑行数组 `r`：`[code, dIdx, pIdx, count, mIdx, eIdx, cIdx, tIdx, lIdx, oIdx, provIdx, nf]`；`prov`=31省名表（兼作分块键），`nf`=备注长度>26 的警示标记（列表页免加载完整 note 即可显示"⚠ 有特殊限制"）。gzip 后网络传输约 232 KB。
- `full/p00.json .. p30.json`：31 个省份分块（p 下标 = prov 数组下标），共 10.17 MB，含全部 12 字段原文（含 note/degree）。详情弹层点击时按需 fetch 单块（gzip 后约 40-90 KB/块）并内存缓存。
- code 在分块内仍不全局唯一（见上方警示），详情定位键 = provIdx + code，与前端收藏键 `code|dept|position` 互相独立。
